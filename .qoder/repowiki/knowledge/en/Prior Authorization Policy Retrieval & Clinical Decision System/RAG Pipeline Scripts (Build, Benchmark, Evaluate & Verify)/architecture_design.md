Each script is an independent entry point (`if __name__ == '__main__': main()`) that imports reusable components from the `rag.*`, `models.*`, `services.*`, `adapters.*`, and `decision.*` packages rather than sharing code with one another. They all read runtime configuration from `config/config.yaml` and operate on persisted artifacts under `paths.*` (raw data, processed chunks, vector store, embeddings). The scripts fall into four roles: (1) data preparation — `build_index.py` normalizes policies, chunks them, generates BGE embeddings, and builds FAISS + BM25 indexes; (2) profiling — `benchmark.py` runs a fixed claim through the full normalized pipeline 100 times, recording per-component latencies and memory usage to `reports/benchmark_report.{json,md}`; (3) evaluation — `evaluate.py` runs a curated set of positive/negative/hard-negative/unknown test cases against the same pipeline and reports recall@k, MRR, accuracy, and cross-policy contamination; (4) verification — `inspect_dataset.py` profiles raw JSON/JSONL inputs, `verify_real_v1_runtime.py` executes real DB-backed claims through `run_integrated_pipeline` with both RAG LLM and NVIDIA Agent-1 LLM, and `verify_v1_final.py` orchestrates eight V1 scenarios across data integrity, schema trace, RAG, Agent-1, performance, API/CLI consistency, and architecture boundary checks. `query_pipeline.py` is the only user-facing CLI that accepts a JSON claim file via argparse and delegates to `services.integrated_pipeline.run_integrated_pipeline` after enriching the claim with payer context via `RuntimeAdapter`.
