All scripts expect `config/config.yaml` and prebuilt artifacts at the paths declared there (processed chunks, FAISS index, BM25 index, embeddings). `verify_real_v1_runtime.py` and `verify_v1_final.py` require `LLM_API_KEY` / `NVIDIA_API_KEY` environment variables (loaded via `python-dotenv`); `verify_v1_final.py` also requires the workspace root to be on `sys.path` and reads `.env` from the repo root. Reports are written to a `reports/` directory created automatically by each script.
