The companion README documents the pipeline commands that consume these assets: `python pa_pipeline/pipeline_main.py ingest` to build the two SQLite databases from the spreadsheets, `run-simulation --patient-id <id> --scenario-type <type>` for deterministic simulations, and `process-manual --file <pdf>` to parse manual clinical PDFs into the provider database. Dependencies are installed via `pip install pandas openpyxl pdfplumber`.
