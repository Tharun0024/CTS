Install via `pip install -r requirements.txt`, configure secrets from `.env.example`, build indexes with `python -m scripts.build_index`, run the full test suite with `python -m pytest -v`, evaluate retrieval with `python -m scripts.evaluate`, benchmark latency with `python -m scripts.benchmark`, start the API server via `uvicorn api.main:app --host 127.0.0.1 --port 8000`, and execute an end-to-end claim query with `python -m scripts.query_pipeline <claim_file>`.
