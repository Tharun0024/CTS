The module is organized as a flat pytest package under `tests/` with no subpackages. It splits into three test families: (1) unit tests for the core `decision` engine (`test_agent.py`, `test_components.py`) that construct `Policy`, `CaseData`, `EvidenceItem`, and `Rule` fixtures via `@pytest.fixture` and assert on `DecisionAgent.evaluate()` outcomes; (2) integration tests for the FastAPI layer (`test_api.py`, `test_integration_cases.py`, `test_v1_integration_fixes.py`, `test_phase5d_runtime_fixes.py`) using `fastapi.testclient.TestClient` against `api.main.app`; and (3) live smoke/benchmark scripts (`gemma_smoke_test.py`, `nvidia_smoke_test.py`, `decision_intelligence_benchmark.py`) that are executable `__main__` entry points requiring `OPENROUTER_API_KEY` and writing per-model JSON reports (`phase4*_benchmark_report.json`). A shared `sys.path.insert(0, ...)` pattern at the top of each script adds the repo root so imports like `from decision import ...` resolve without installing the package. Tests depend only on the sibling `decision/`, `rag/`, `models/`, and `api/` packages — there are no cross-test dependencies between files.
