Live smoke/benchmark scripts require an `OPENROUTER_API_KEY` environment variable (loaded from a local `.env` file via a built-in parser in `gemma_smoke_test.py`) and can be run directly with `python tests/gemma_smoke_test.py`, `python tests/nvidia_smoke_test.py`, or `python tests/decision_intelligence_benchmark.py`. Unit/integration tests are run via `pytest tests/` and read fixture data from `config/config.yaml` and prebuilt vector stores referenced by that config.
